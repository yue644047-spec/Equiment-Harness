一、背景与目标

保留 DeepSeek Harness 内核，把前端重做成个人工作台：用户有一个固定入口界面，从它出发触达一切能力；工作台承载个人知识，并可登记、启动、发布自有项目。

2026-09-30 与用户逐轮敲定的顶层信息架构（D13）是本次改造的核心，一句话概括：一切内容归属项目。

维度定稿内容
项目空间22 个可开关页签，内容生产全部下沉到项目内
项目模板学术研究 / 软件开发 / 学习笔记 / 数据集工程 / 空白（决定默认开启页签）
全局层10 项：仪表盘、每日小结、应用中心、Dify 智能链、全局问答、设置、回收站+备份、通知中心、数据看板、多大脑空间
智能体每个功能模块 = 一个大智能体；D1 数据底座兼任触发编排器，只触发大智能体
桌宠Q 版 chibi，可拖拽、点击互动、兼任全局问答入口、显示 API 余额、成长系统
