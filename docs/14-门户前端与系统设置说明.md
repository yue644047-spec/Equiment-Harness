# 14 · 门户前端与「系统设置」说明

> 适用对象：内网运维（平台运维组）、质量治理岗、演示讲解人员。
> 前置文档：04（Web 界面选型与硬约束）、10（治理度量框架）、13（Windows 演示系统说明）。
> 本文说明门户前端（墨刀 Vue 原型改造版）的页面结构，以及本次新增的「系统设置」能力与后端契约。

## 1. 页面清单

门户为单页应用（hash 路由），登录后由顶部导航 + 左侧分组菜单组织：

| 分组 | 页面 | 路由 | 主要数据来源 |
| --- | --- | --- | --- |
| 智能问答 | 智能问答 | `/chat` | `POST /api/chat/stream`（Dify 会话流） |
| 智能问答 | 检索测试 | `/retrieval` | `POST /api/kb/retrieval-test` |
| 智能问答 | 知识库与资料 | `/knowledge` | `GET /api/kb/datasets*` |
| 智能问答 | 知识图谱 | `/graph` | `GET /api/kb/datasets/{id}/graph` |
| 智能编排 | 应用工作室 | `/studio` | `GET /api/orchestration/apps` |
| 智能编排 | 编排工作台（Dify 式可视化编辑器） | `/orchestration` | `GET /api/orchestration/apps/{id}`（原始 DSL）/ `POST /api/orchestration/workflows`（保存并发布）/ `POST .../run`（试运行）/ `GET .../runs`（运行记录） |
| 质量治理 | 文档质量记分卡 | `/scorecard` | `GET /api/gov/summary` |
| 质量治理 | 缺陷整改单 | `/defects` | `GET /api/gov/defects` |
| 平台运维 | 服务状态 | `/health` | `GET /api/health` |
| 平台运维 | **进程资源管理器（本次新增）** | `/processes` | `GET /api/platform/processes`（快照 + 阈值告警）· `GET /api/platform/processes/export`（CSV/JSON 快照）· `POST /api/platform/kernels/{name}/restart`（一键重启内核）· `POST /api/platform/processes/{pid}/kill`（结束进程） |
| 平台运维 | **系统设置（本次新增）** | `/settings` | `GET /api/settings` |

入口有三处：顶栏齿轮按钮、左侧菜单「平台运维 › 系统设置」、右上角账号菜单「系统设置」。

## 2. 系统设置页包含什么

1. **四个总览指标**：门户版本、BFF 连续运行时长、服务端凭据就绪数（已配置 / 总数）、依赖服务在线数。
2. **账号与权限**：当前工号 / 姓名 / 角色 / 会话有效期、服务端账号清单（工号、姓名、角色）、切换账号与退出登录。
3. **服务端凭据就绪情况**：逐项列出密钥用途、对应环境变量、是否已配置、来源（进程环境变量或 `.env`）与短指纹。
4. **上游服务地址**：Dify API、Dify 插件守护进程、RAGFlow、Elasticsearch、本地向量模型、MySQL、Redis 的实际地址与职责，可一键重新检测在线状态。
5. **模型与治理策略**：编排主模型 / 快速模型 / 向量模型与维度，以及版本硬过滤、召回 Top-K、评价量表、归因口径、DQI 合格线、CSI 目标、回执通道等只读策略。
6. **界面偏好**：登录后默认进入页面、默认召回条数、默认是否包含作废版本、问答是否展示引用条款；保存于本机浏览器。
7. **运行环境与诊断**：BFF 运行时、配置文件路径、治理库路径、部署形态，以及「复制诊断信息」（不含密钥）与「清除本地会话缓存」。

## 3. 后端契约 `GET /api/settings`

需要登录（会话 Cookie）。**不返回任何密钥明文**，硬约束见 04 号文档第 1 条。

| 字段 | 说明 |
| --- | --- |
| `portal` | 门户名称、BFF 版本、运行时、启动时间、运行时长、会话有效期、配置文件路径及是否存在 |
| `viewer` | 当前账号：工号、姓名、角色、是否管理员 |
| `accounts` | 服务端已配置账号清单（工号 / 姓名 / 角色 / 是否当前账号），**不含口令** |
| `credentials` | 凭据清单：用途、环境变量名、是否已配置、来源、短指纹（仅管理员可见） |
| `upstreams` | 上游服务名称、地址、职责 |
| `models` | 模型供应商、编排主模型、快速模型、向量模型与向量维度 |
| `policy` | 版本策略、召回 Top-K、评价量表、归因口径、缺陷规则集、DQI / CSI / 闭环率目标、回执通道 |
| `governance` | 治理服务目录、治理库路径及是否存在 |

安全约定：

- 密钥只在 BFF 进程内使用，浏览器与前端代码中不保存任何密钥；
- 指纹为密钥 SHA-256 摘要的前 10 位，用于运维核对「加载的是哪一把密钥」，无法反推密钥；
- 指纹仅对 `role=admin` 的账号返回，其他账号得到空串（页面显示「仅管理员可见」）。

## 4. 账号与角色

账号由服务端 `E:\llm-stack\.env` 的 `PORTAL_USERS` 维护，格式：

```
PORTAL_USERS=工号:口令:显示名:角色,工号:口令:显示名:角色
```

- 角色取值：`admin`（系统管理员）、`auditor`（质量审核员）、`user`（业务用户，缺省值）。
- 当前演示环境：`admin / admin123`，角色 `admin`。
- 口令或账号变更后需重启 BFF 生效（见第 6 节）。

## 5. 界面偏好（浏览器本地）

存储位置：`localStorage["equipment-portal.preferences"]`，只在当前浏览器生效，不落库、不上报。

| 偏好 | 默认值 | 生效位置 |
| --- | --- | --- |
| `defaultPath` | `/chat` | 登录成功后的跳转目标，以及访问门户首页 `/` 时的重定向 |
| `retrievalTopK` | 5 | 智能问答的 `inputs.top_k`、检索测试的默认召回条数（1–20） |
| `includeObsolete` | false | 上述两个页面的默认「包含作废版本」开关 |
| `showCitations` | true | 问答结果是否展示引用条款（治理归因仍在服务端记录） |

需要强调：界面偏好只是**默认入参**，资料现行版本硬过滤、评价量表、归因口径等治理策略由服务端与检索契约强制，页面无法放宽。

## 6. 运维操作

```powershell
# 1) 修改账号或密钥
notepad E:\llm-stack\.env

# 2) 重启 BFF（密钥与账号在进程启动时载入）
cd D:\llm-stack\src\portal\bff
& .venv\Scripts\python.exe -m uvicorn main:app --host 127.0.0.1 --port 8090

# 3) 前端改动后重新构建（BFF 直接托管 dist）
cd D:\llm-stack\src\portal\web-modao\equipment-portal.vue
pnpm exec vue-tsc --noEmit
pnpm build
```
